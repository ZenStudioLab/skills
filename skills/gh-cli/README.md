# GitHub CLI (gh)

Complete GitHub CLI reference for repositories, issues, pull requests, Actions, projects, releases, and all command-line GitHub operations.

Covers 20+ command categories including repos, issues, PRs, workflows, projects, releases, gists, codespaces, organizations, and search with 100+ subcommands. Supports authentication modes (interactive login, tokens, GitHub Enterprise), configuration via environment variables, and multi-account switching. Includes JSON output filtering with jq, custom templates, pagination, and API request capabilities for advanced workflows. Provides common patterns for bulk operations, fork syncing, CI/CD automation, and repository setup with shell integration and aliases.

## Installation

```bash
npx skills add ZenStudioLab/skills --skill gh-cli
```

## What's Covered

- Installation and authentication setup
- Complete CLI command tree
- Repository management (create, clone, fork, sync, delete)
- Issue tracking (create, list, edit, close, comment)
- Pull requests (create, review, merge, checks, revert)
- GitHub Actions (workflows, runs, caches, secrets, variables)
- Projects (boards, items, fields)
- Releases and release assets
- Gists and codespaces
- Organizations and search
- Labels, SSH keys, GPG keys
- API requests (REST + GraphQL)
- Configuration, extensions, aliases
- Output formatting (JSON with jq, Go templates)
- Common workflows and best practices
